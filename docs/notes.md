# 小荧上班 · 产品结论

整理自 2026-09 这次对话。运行方式和目录说明见根目录 `README.md`。

## 定位

一句话：今日上班仪表盘。打开就能看到还要上多久、已经赚了多少、这些钱能换什么。

核心不是打卡或发工资，而是把上班时间翻译成可见的钱和进度：倒计时减压，实时收入给正反馈，购买力把抽象工资换成咖啡、午餐。吉祥物「小荧」负责陪伴，让它不像表格。

数据只存在本机，不登录、不接后端。个人主体小程序即可，暂时不需要微信支付。

不要做成：考勤打卡、工资发放、报销、薪资平台、金融理财。对外话术写成「上班倒计时小工具」，不要承诺赚钱。

## 一期范围（当前已落地）

四个 Tab：今日 / 换算 / 日历 / 我的。英文 eyebrow 字号和颜色全站一致（`CALCULATOR` / `CALENDAR` / `PROFILE`，今日是 `WORK TODAY 今天也很棒`）。

**今日**（扫一眼，不算账本）

1. 顶栏：日期星期 + 状态胶囊（休息时点胶囊进日历，否则进我的）
2. 主卡：上班中倒计时；下班或休息后改显示金额。鼓励文案、今日已赚、已上班天数 / 本月累计入口、小荧
3. 进度卡：上班 — 百分比 — 下班；有午休才显示午休行。轨道 `#efe8db`、填充 `#7c6246`
4. 时薪 / 分薪 / 秒薪三列
5. 购买力：默认咖啡 ¥15 / 杯、午餐 ¥35 / 份；「全部换算 ›」进换算「今天能换」
6. 备忘 +「小荧陪你」（要留）
7. 没有页面内分享按钮，只用右上角

今日**不放**先赚回。未保存过月薪（`salaryReady === false`）时，倒计时和进度照常，金额改成「写月薪后就能看」。默认备忘为空。

**换算**

分段器三档，**先赚回**在第一位，然后是今天能换、想买的。滑块有位移动画；下面内容直接切换，不要横滑、不要跟高度。不要做成全局「净赚模式」：净赚只出现在先赚回主卡、且当天已覆盖时。名称就叫「先赚回」，不要改成固定支出 / 每日支出。

- **先赚回**：自己填名称和每月金额，最多 5 项。日均 = `月合计 / 本月上班天数`。工具栏：`摊到每个上班日 · 本月合计 ¥…`（月合计只放这里，不进列表、不进主卡）。深色主卡：每个上班日先赚回；已覆盖则右侧出净赚；进度条对照今日已赚。深色卡进度条用页面米色 `#efe8db` 填、墨色槽，不要套今日白卡的焦糖，也不要用金。列表左列名称 + ¥/月，右列该项日均。先点编辑再改，完成才存；离开丢掉未完成的改动
- **今天能换**：按今日已赚换算默认商品，并显示一件要上多久（`单价 / 秒薪`）。编辑单价同上
- **想买的**：自己填名称和价格，按 `价格 / 日薪` 看要上几天班，最多 5 件。编辑同上

今日购买力点「全部换算」会切到「今天能换」档（`useCalcTab`）。加班、改咖啡午餐的名字仍是后面的事。

**日历**

- 当月格子。先点「编辑」再改休息制度或单日。制度：双休 / 休周六 / 休周日 / 大小周，马上重画格子
- 观看时标题带制度；大小周还要标「本周大周」或「本周小周」：大周休周日，小周双休
- 法定节假日默认休息，调休补班默认上班（2025、2026 国务院通知，写在 `holidays.ts`）
- 离开页面会 `onHide` 退出编辑
- 累计卡：本月累计金额 +「本月上班 X 天，已上班 Y 天」，**不要**再写今日已赚
- 格子上假日标「休」、调休标「班」

**我的**：标题「工作设置」。月薪、上下班、午休（可关）。直接改，有效就存到本地，没有编辑/完成。不要「工作参数」分组标题。没保存过月薪时输入框空着，不要预填 `12223`。休息日和每月工作日不手填，由日历算出。商品单价不在这里改。`Profile.workDaysPerMonth` 还在类型和本地存储里（默认 `22`，保存时写成当月天数），算薪不读它，只读 `countWorkDaysInMonth()`。

工作状态五种：`before` / `working` / `lunch` / `after` / `off`。下班或休息后收入和进度封顶。

## 工时与算薪

```
本月上班天数 = 日历上未标休息的天数
日薪         = 月薪 / 本月上班天数
有效工时     = 下班 − 上班 − 午休
秒薪         = 日薪 / 有效秒数
今日已赚     = 已工作秒数 × 秒薪
已上班天数   = 本月到昨天的上班日 +（今天已开工则再加 1）
本月累计     = 已过上班日 × 日薪 + 今日已赚
日均固定支出 = 本月固定支出合计 / 本月上班天数
```

默认谁休息、谁上班（用户没改日历时）：

1. 用户点过的日期优先（`offDates` / `workDates`）
2. 国务院调休补班 → 上班
3. 国务院放假 → 休息
4. 休息制度 → 休息（默认双休；可改成休周六、休周日、大小周）
5. 其余日子 → 上班

午休：默认有，`12:00`–`13:00`，必须夹在上班和下班之间，不计薪。可在「我的」改成没有午休，这时工时不扣午休，今日页也不显示午休那一行。

默认班次：存储里月薪仍是 `12223`，但小程序未保存前不展示金额、设置页也不预填。`09:00`–`19:00`。小程序备忘默认空。设置键名 `work-today-profile-v1`。

## 商业

价值在情绪和习惯，不在算薪精度。同类功能不稀缺，用户几乎不会为「算时薪」付费。差异靠三件事叠在一起：时间变钱、一天看得见、小荧像角色。

现阶段（个人号）：

- 不能接微信支付，也很难做会员
- 先靠小红书 / 朋友圈截图传播
- 用「小荧上班」当角色 IP，不要只当工具名
- 日活起来后再看流量主广告

以后换企业 / 个体户主体再考虑：自定义商品、加班、皮肤、去广告、云同步、年度报告。

不要押：考勤发工资、一上来做社区摸鱼、靠「帮你多赚钱」获客。

## 技术结论

只做微信小程序（uni-app Vue 3），不要再加第二套页面。算薪公式以这份笔记为准，不要在 README 再抄一份。实现在 `src/utils/work.ts`、`holidays.ts`、`types.ts`。

实现上踩过的坑：

- 金额不要用 `toLocaleString`，用 `formatMoney` / `formatWage`
- 小程序设置页输入框要包一层、固定高度，不要垂直 padding
- 分享必须写在页面上的 `onShareAppMessage`
- 分享到朋友圈：未正式发布前微信会一直灰
- 未发布时，只有开发者 / 体验者能打开分享卡片
- 微信开发者工具导入 `dist/dev/mp-weixin`
- 装依赖用 `npm install --legacy-peer-deps`
