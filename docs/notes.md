# 小荧上班 · 产品结论

整理自 2026-09 这次对话。运行方式和目录说明见根目录 `README.md`。

## 定位

一句话：今日上班仪表盘。打开就能看到还要上多久、已经赚了多少、这些钱能换什么。

核心不是打卡或发工资，而是把上班时间翻译成可见的钱和进度：倒计时减压，实时收入给正反馈，购买力把抽象工资换成咖啡、午餐。吉祥物「小荧」负责陪伴，让它不像表格。

数据只存在本机，不登录、不接后端。个人主体小程序即可，暂时不需要微信支付。

不要做成：考勤打卡、工资发放、报销、薪资平台、金融理财。对外话术写成「上班倒计时小工具」，不要承诺赚钱。

## 一期范围（当前已落地）

四个 Tab：今日 / 换算 / 日历 / 我的。

**今日**

1. 顶栏：`WORK TODAY 今天也很棒` + 日期星期 + 状态胶囊（休息时点胶囊进日历）
2. 主卡：倒计时、鼓励文案、今日已赚、本月累计 / 已上班天数入口、小荧
3. 进度：上班时间 — 百分比 — 下班时间
4. 时薪 / 分薪 / 秒薪
5. 购买力：默认咖啡 ¥15 / 杯、午餐 ¥35 / 份
6. 备忘 +「小荧陪你」
7. 没有页面内「分享给朋友」按钮，分享只用右上角

小程序：未在「我的」保存过月薪时（`salaryReady === false`），倒计时和进度照常，金额改成「写月薪后就能看」。默认备忘为空。H5 暂不跟。

**日历**

- 当月格子，周末默认休息
- 法定节假日默认休息，调休补班默认上班（2025、2026 国务院通知，写在 `holidays.ts`）
- 先点「编辑」再点日期才能改。小程序离开页面会 `onHide` 退出编辑；H5 靠路由卸载重置，没有单独写退出逻辑
- 展示：本月累计金额；一行「本月上班 X 天，已上班 Y 天」
- 格子上假日标「休」、调休标「班」

**我的**：月薪、上下班、午休、备忘。每月工作日不手填，由日历上班天数算出。商品单价不在这里改。`Profile.workDaysPerMonth` 还在类型和本地存储里（默认 `22`，保存时写成当月天数），算薪不读它，只读 `countWorkDaysInMonth()`。

**换算**：按今日已赚换算商品，并显示一件要上班多久（`单价 / 秒薪`，按当前班次）。先点「编辑」再改单价，点「完成」才存；离开页面丢掉未完成的改价。加班、改商品名、再加一件仍是后面的事。

工作状态五种：`before` / `working` / `lunch` / `after` / `off`。下班或休息后收入和进度封顶。

## 工时与算薪

```
本月上班天数 = 日历上未标休息的天数
日薪         = 月薪 / 本月上班天数
有效工时     = 下班 − 上班 − 午休
秒薪         = 日薪 / 有效秒数
今日已赚     = 已工作秒数 × 秒薪
已上班天数   = 本月到昨天的上班日 +（今天已开工则再加 1）
本月累计     = 已过上班日 × 日薪 + 今日已赚
```

默认谁休息、谁上班（用户没改日历时）：

1. 用户点过的日期优先（`offDates` / `workDates`）
2. 国务院调休补班 → 上班
3. 国务院放假 → 休息
4. 周末 → 休息
5. 其余工作日 → 上班

午休：默认 `12:00`–`13:00`，必须夹在上班和下班之间；午休不计薪。

默认班次：月薪 `12223`（小程序未保存前不展示金额），`09:00`–`19:00`。小程序备忘默认空。设置键名 `work-today-profile-v1`。

## 商业

价值在情绪和习惯，不在算薪精度。同类功能不稀缺，用户几乎不会为「算时薪」付费。差异靠三件事叠在一起：时间变钱、一天看得见、小荧像角色。

现阶段（个人号）：

- 不能接微信支付，也很难做会员
- 先靠小红书 / 朋友圈截图传播
- 用「小荧上班」当角色 IP，不要只当工具名
- 日活起来后再看流量主广告

以后换企业 / 个体户主体再考虑：自定义商品、加班、皮肤、去广告、云同步、年度报告。

不要押：考勤发工资、一上来做社区摸鱼、靠「帮你多赚钱」获客。

## 技术结论

两端分开写是对的：根目录 H5（Vue 3 + Vite），`mp/` 微信小程序（uni-app Vue 3）。页面、样式、生命周期不要合成一套组件。

业务逻辑在复制：`work.ts`、`holidays.ts`、`types.ts` 必须两端同步。算薪公式以这份笔记为准，不要在 README 再抄一份。体量大了再抽 `packages/core`，现在不必。

实现上踩过的坑：

- 金额不要用 `toLocaleString`，用 `formatMoney` / `formatWage`
- 小程序设置页输入框要包一层、固定高度，不要垂直 padding
- 分享必须写在页面上的 `onShareAppMessage`
- 分享到朋友圈：未正式发布前微信会一直灰
- 未发布时，只有开发者 / 体验者能打开分享卡片
- 微信开发者工具导入 `mp/dist/dev/mp-weixin`
- `mp` 装依赖用 `npm install --legacy-peer-deps`
