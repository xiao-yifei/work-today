# 小芽上班 · 产品结论

整理自 2026-09 对话。运行方式和目录说明见根目录 `README.md`。

## 定位

一句话：今日上班仪表盘。打开就能看到还要上多久、已经赚了多少、这些钱能换什么。

核心不是打卡或发工资，而是把上班时间翻译成可见的钱和进度：倒计时减压，实时收入给正反馈，购买力把抽象工资换成咖啡、午餐。吉祥物「小芽」负责陪伴，让它不像表格。对外不用「荧 / 荧光 / WORK TODAY」，避免和同类小程序「荧光时间」撞名。

数据只存在本机，不登录、不接后端。个人主体小程序即可，暂时不需要微信支付。

不要做成：考勤打卡、工资发放、报销、薪资平台、金融理财。对外话术写成「上班倒计时小工具」，不要承诺赚钱。加班只是自己记一笔时长和算法，不要做成工资条，也不要按劳动法 1.5 倍算。

## 一期范围（当前已落地）

四个 Tab：今日 / 换算 / 日历 / 我的。换算 / 日历 / 我的 eyebrow 仍是 `CALCULATOR` / `CALENDAR` / `PROFILE`；今日是 `WORKDAY · SPROUT`，不要写 WORK TODAY。只做微信小程序，H5 不做。导航栏和分享标题用「小芽上班」。

**今日**（扫一眼，不算账本）

1. 顶栏：日期星期 + 状态胶囊。休息、等待加班、加班中点胶囊进日历，否则进我的
2. 主卡：上班中倒计时到下班；午休倒计时到午休结束；等待加班倒计时到加班开始（「距离加班还有」，这段不计加班）；加班中倒计时到加班结束。上班前倒计时到上班。下班或休息后大钟停在 `00:00:00`，文案收工。副文案上班中按剩余时间变：≥4 小时「刚开工，我陪你慢慢来」；≥2 小时「走过一截了，辛苦啦」；≥1 小时「后半段了，我还在」；不到 1 小时才写「再撑一会儿就下班了」。收工是「收工了，去干点想干的」。今日已赚、已上班天数 / 本月累计入口、小芽。「扣支出」打开时，上班中标签改成「扣除支出后」，金额用扣除后口径
3. 进度卡：上班 — 百分比 — 下班（当天有加班时终点是加班结束）。当天有加班时，进度按「已工作 /（有效工时 + 加班）」走，避免下班后跳满、加班开始再回跳。午休行只在午休中显示；加班行从加班开始时刻起显示（加班中或加完后保留），未到点不提前写
4. 时薪 / 分薪 / 秒薪三列。今日卡不写日薪、不放「扣支出」开关。开关在「我的」，默认关。打开后按时薪口径重算（日薪 − 日均固定支出），主卡、时薪三列、购买力、今天能换、想买的、日历累计、设置页预览一起变。加班中且当天是固定时薪时，三列改按该固定时薪拆，固定时薪本身不跟扣支出。状态胶囊：只有「今天休息」用焦糖 `#7c6246`，上班中 / 加班中 / 等待加班用深墨 `#2b2a26`
5. 购买力：默认咖啡 ¥15 / 杯、午餐 ¥25 / 份；首页只显示头两件，名称跟换算页走。说明留「把今天的努力，换成生活里的小确幸」。「全部换算 ›」进换算「今天能换」。跟「扣支出」开关走，按当前口径的今日已赚换算
6. 备忘在首页，点编辑改，完成或离开页面才收起。默认空，不要预填示例句子
7. 陪伴标题「小芽陪你」。上班中还早时：「还有 xx，我在这儿坐着。」
8. 没有页面内分享按钮，只用右上角。分享标题：`小芽上班 · 看看距离下班还有多久`

今日**不放**先赚回。未保存过月薪（`salaryReady === false`）时，倒计时和进度照常，金额改成「写月薪后就能看」。没填月薪时不展示时薪三列。

**换算**

分段器三档，**先赚回**在第一位，然后是今天能换、想买的。滑块有位移动画；下面内容直接切换，不要横滑、不要跟高度。不要做成默认全局「净赚模式」：换算页先赚回的净赚只出现在该档主卡、且当天已覆盖时，始终对照毛收入的今日已赚，避免把支出扣两遍。「我的」可以开关看扣除支出后的时薪口径，默认关；打开后购买力、今天能换、想买的跟开关走。名称就叫「先赚回」，不要改成固定支出 / 每日支出。

- **先赚回**：自己填名称和每月金额，最多 5 项。日均 = `月合计 / 本月上班天数`。工具栏：`摊到每个上班日 · 本月合计 ¥…`（月合计只放这里，不进列表、不进主卡）。深色主卡：每个上班日先赚回；已覆盖则右侧出净赚，并收掉进度条。没盖满时进度条对照今日已赚 / 日均支出，槽用 `rgba(246, 241, 232, 0.16)`，填充 `#efe8db`，不要套今日白卡的焦糖，也不要用金。列表左列名称 + ¥/月，右列该项日均。先点编辑再改，完成才存；离开丢掉未完成的改动。没有项目时不必放「加一项」；有了之后用整行深墨按钮
- **今天能换**：按当前口径的今日已赚换算商品，并显示一件要上多久（`单价 / 秒薪`）。可改名称、单价，最多 5 件；前两件不能删除。没有第三件时不必硬放加一件；要加用浅底虚线卡片。「扣支出」打开时工具栏写成「按扣除支出后 ¥…」。空状态标题和首页购买力说明一样，留「把今天的努力，换成生活里的小确幸」
- **想买的**：自己填名称和价格，按 `价格 / 日薪` 看要上几天班，最多 5 件。单列票卡，编辑在卡片上改，删除在右上。加一件是整行深墨按钮。工具栏带上当前日薪金额。「扣支出」打开时按扣除后日薪；日薪 ≤ 0 时写「扣除支出后不够」

今日购买力点「全部换算」会切到「今天能换」档（`useCalcTab`）。

**日历**

- 当月格子。观看时点上班日记加班；休息日 toast「休息日先改成上班，再记加班」
- 加班弹层：进出场约 200ms，遮罩淡入、卡片上滑，里面芯片不要再加动画。时长预设 不用了 / 1 小时 / 2 小时 / 3 小时 / 其他（时间选择器）。有时长后可改开始时刻、平时秒薪或固定时薪。单日最多 8 小时。开始时刻可晚于当天下班点；下班到加班开始之间不计加班
- 弹层副文案：今天写「到点后，从加班开始时刻才计加班」；其他日子写「当日收入约 ¥…」（日薪 + 这天加班，跟扣支出口径）；没写月薪则「写月薪后看当日收入」
- 先点「编辑」再改休息制度或单日。制度：双休 / 休周六 / 休周日 / 大小周，马上重画格子。离开页面 `onHide` 退出编辑并关掉加班弹层
- 观看时标题带制度；大小周还要标「本周大周」或「本周小周」：大周休周日，小周双休
- 法定节假日默认休息，调休补班默认上班（2025、2026 国务院通知，写在 `holidays.ts`）
- 累计卡：本月累计金额 +「本月上班 X 天，已上班 Y 天」，**不要**再写今日已赚。金额含已记加班。「扣支出」打开时标题改成「本月累计 · 已扣固定支出」
- 格子上假日标「休」、调休标「班」、加班标「加」

**我的**：标题「工作设置」。月薪、上下班、午休（可关）、扣除支出。直接改，有效就存到本地，没有编辑/完成。不要「工作参数」分组标题。没保存过月薪时输入框空着，不要预填 `12223`。休息日和每月工作日不手填，由日历算出。商品单价不在这里改。`Profile.workDaysPerMonth` 还在类型和本地存储里（默认 `22`，保存时写成当月天数），算薪不读它，只读 `countWorkDaysInMonth()`。预览主数字是时薪，下一行写上班天数和日薪。月薪输入整行填写。本月加班合计大于 0 时，框下才出现：`本月加班 ¥… · 总收入 ¥…`（总收入 = 月薪 + 本月加班合计，毛口径，不跟扣支出）。没写月薪或没有加班时不出现这行。扣除支出开关在表单最后一行，和午休同一套，不要叠到预览卡上。打开后预览文案改成「扣掉固定支出后，时薪约为」。今日不放这个开关。`Profile.showAfterCosts` 记在本地，默认 `false`。

工作状态：`before` / `working` / `lunch` / `awaiting` / `overtime` / `after` / `off`。下班后到加班开始是 `awaiting`。没有加班、或加班开始时刻不晚于下班点时，下班后直接 `after`。休息日收入和进度为 0。

## 工时与算薪

```
本月上班天数     = 日历上未标休息的天数
日薪             = 月薪 / 本月上班天数
有效工时         = 下班 − 上班 − 午休（关闭午休则不扣）
秒薪             = 日薪 / 有效秒数
已工作秒数       = 有效工时内已过秒数（不含午休；等待加班不加加班秒）
加班开始         = max(当天记录的开始时刻, 下班点)
加班结束         = 加班开始 + 当天加班分钟
加班秒薪         = 固定时薪 / 3600，否则用当天秒薪
加班费（一天）   = 加班分钟 × 60 × 加班秒薪
今日已赚         = min(已工作秒数, 有效工时) × 秒薪 + 已发生加班秒 × 加班秒薪
已上班天数       = 本月到昨天的上班日 +（今天已开工则再加 1；等待加班 / 加班 / 下班后都算已开工）
本月加班合计     = 当月每个上班日的加班费之和（含今天已记的，按当前秒薪或该日固定时薪）
本月累计         = 已过上班日 × 日薪 + 今日已赚
设置页总收入     = 月薪 + 本月加班合计
日均固定支出     = 本月固定支出合计 / 本月上班天数
扣除支出后日薪   = 日薪 − 日均固定支出
扣除支出后时薪 / 分薪 / 秒薪 = 按扣除支出后日薪重算
扣除支出后今日已赚 = 已工作秒数 × 扣除支出后秒薪 + 已发生加班秒 × 加班秒薪
                    （固定时薪加班仍用固定时薪；平时秒薪加班才跟扣除后秒薪）
扣除支出后本月累计 = 已过上班日 × 扣除支出后日薪 + 扣除支出后今日已赚
```

今日「扣支出」开关打开时，主卡、时薪三列、购买力、今天能换、想买的、日历累计、设置页预览用扣除后口径。先赚回仍对照毛收入的今日已赚。这和先赚回的「先覆盖再算剩余」不是同一套：开关是把支出摊进每一秒，先赚回是看今天有没有赚回日均。设置页「本月加班 · 总收入」始终用未扣支出的月薪和加班合计。

默认谁休息、谁上班（用户没改日历时）：

1. 用户点过的日期优先（`offDates` / `workDates`）
2. 国务院调休补班 → 上班
3. 国务院放假 → 休息
4. 休息制度 → 休息（默认双休；可改成休周六、休周日、大小周）
5. 其余日子 → 上班

把一天改成休息会清掉那天的加班。加班不能记在休息日。

午休：默认有，`12:00`–`13:00`，必须夹在上班和下班之间，不计薪。可在「我的」改成没有午休，这时工时不扣午休。

默认班次：存储里月薪仍是 `12223`，但小程序未保存前不展示金额、设置页也不预填。`09:00`–`19:00`。小程序备忘默认空。设置键名 `work-today-profile-v1`。商品最多 5 件，前两件默认咖啡、午餐，不能删除；想买的、先赚回各最多 5 项。

## 商业

价值在情绪和习惯，不在算薪精度。同类功能不稀缺，用户几乎不会为「算时薪」付费。差异靠三件事叠在一起：时间变钱、一天看得见、小芽像角色。

现阶段（个人号）：

- 不能接微信支付，也很难做会员
- 先靠小红书 / 朋友圈截图传播
- 店名和角色都用「小芽上班 / 小芽」，不要只当工具名
- 日活起来后再看流量主广告

以后换企业 / 个体户主体再考虑：皮肤、去广告、云同步、年度报告。

不要押：考勤发工资、一上来做社区摸鱼、靠「帮你多赚钱」获客。

## 技术结论

只做微信小程序（uni-app Vue 3），不要再加第二套页面。算薪公式以这份笔记为准，不要在 README 再抄一份。实现在 `src/utils/work.ts`、`holidays.ts`、`types.ts`。

实现上踩过的坑：

- 金额不要用 `toLocaleString`，用 `formatMoney` / `formatWage`
- 小程序设置页输入框要包一层、固定高度，不要垂直 padding
- 分享必须写在页面上的 `onShareAppMessage`
- 分享到朋友圈：未正式发布前微信会一直灰
- 未发布时，只有开发者 / 体验者能打开分享卡片
- 微信开发者工具导入 `dist/dev/mp-weixin`
- 装依赖用 `npm install --legacy-peer-deps`
- 弹层里的时间选择器不要在内部 view 上 `@click.stop`，否则点不开；确定时要防遮罩误关，开始时刻要原样写入，不要只保存晚于下班点的
- 当天有加班时进度分母要含加班，否则下班后 100%、加班开始再回跳
