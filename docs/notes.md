# 小荧上班 · 产品结论

整理自 2026-09 这次对话。运行方式和目录说明见根目录 `README.md`。

## 定位

一句话：今日上班仪表盘。打开就能看到还要上多久、已经赚了多少、这些钱能换什么。

核心不是打卡或发工资，而是把上班时间翻译成可见的钱和进度：倒计时减压，实时收入给正反馈，购买力把抽象工资换成咖啡、午餐。吉祥物「小荧」负责陪伴，让它不像表格。

数据只存在本机，不登录、不接后端。个人主体小程序即可，暂时不需要微信支付。

不要做成：考勤打卡、工资发放、报销、薪资平台、金融理财。对外话术写成「上班倒计时小工具」，不要承诺赚钱。

## 一期范围

四个 Tab：今日 / 换算 / 日历 / 我的。

**今日（完整）**

1. 顶栏：`WORK TODAY 今天也很棒` + 日期星期 + 状态胶囊
2. 主卡：倒计时、鼓励文案、今日已赚、本月累计入口、小荧
3. 进度：上班时间 — 百分比 — 下班时间，中间写已工作时长
4. 时薪 / 分薪 / 秒薪
5. 购买力：默认咖啡 ¥15 / 杯、午餐 ¥35 / 份
6. 备忘 +「小荧陪你」

**我的（最小设置）**：月薪、每月工作日、上下班、午休、备忘、两件商品单价。

**换算 / 日历**：一期用今日已赚和本月估算占位。加班、自定义商品、按天回看、补记加班、标记休息日放到二期。

工作状态四种：`before` 未上班 / `working` 正在上班 / `lunch` 午休中 / `after` 已下班。下班后收入和进度封顶。

## 工时与算薪

```
日薪     = 月薪 / 每月工作日
有效工时 = 下班 − 上班 − 午休
秒薪     = 日薪 / 有效秒数
今日已赚 = 已工作秒数 × 秒薪
本月累计 = 本月昨日之前的工作日 × 日薪 + 今日已赚
```

午休规则（后补进一期，必须保留）：

- 默认 `12:00`–`13:00`，必须夹在上班和下班之间
- 午休不计薪：倒计时切到「距离午休结束还有」，收入和进度停住
- 例：`09:00`–`19:00` 扣 1 小时，按 9 小时算薪

默认配置：月薪 `12223`，每月 `22` 天，`09:00`–`19:00`。设置键名 `work-today-profile-v1`。

## 商业

价值在情绪和习惯，不在算薪精度。同类功能不稀缺，用户几乎不会为「算时薪」付费。差异靠三件事叠在一起：时间变钱、一天看得见、小荧像角色。

现阶段（个人号）：

- 不能接微信支付，也很难做会员
- 先靠小红书 / 朋友圈截图传播（倒计时、今日已赚、能换几杯咖啡）
- 用「小荧上班」当角色 IP，不要只当工具名
- 日活起来后再看流量主广告

以后换企业 / 个体户主体再考虑：自定义商品、加班、皮肤、去广告、云同步、年度报告；或轻团队氛围应用、餐饮联名。客单价会很低。

不要押：考勤发工资、一上来做社区摸鱼、靠「帮你多赚钱」获客。

## 技术结论

两端分开写是对的：根目录 H5（Vue 3 + Vite），`mp/` 微信小程序（uni-app Vue 3）。页面、样式、生命周期不要合成一套组件。

现在不理想的是业务逻辑在复制。`work.ts`、`types.ts` 必须两端同步；改根目录后拷到 `mp/src/`。体量大了再抽 `packages/core`，现在不必。

实现上踩过的坑：

- 金额不要用 `toLocaleString`，用 `formatMoney` / `formatWage`（安卓微信会出问题）
- 小程序设置页输入框要包一层、固定高度，不要垂直 padding（安卓会裁数字）
- 分享必须写在**页面**上的 `onShareAppMessage`，不能只放 composable，否则右上角转发一直灰
- 分享到朋友圈：未正式发布前微信会一直灰，代码绕不过去
- 未发布时，只有开发者 / 体验者能打开分享卡片
- 微信开发者工具导入的是 `mp/dist/dev/mp-weixin`，不是 `mp` 源码根目录
- `mp` 装依赖用 `npm install --legacy-peer-deps`（Pinia 与 Vue 版本冲突）
