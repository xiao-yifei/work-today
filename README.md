# 小芽上班

上班倒计时 + 实时算薪 + 购买力换算。微信小程序，数据只存在本机，没有账号，也不上传服务器。

技术栈：uni-app Vue 3 + Vite + Pinia。店名和角色都是「小芽」。四个 Tab：今日 / 换算 / 日历 / 我的。只做小程序，不要再加 H5 页面。对外不用「荧 / 荧光 / WORK TODAY」。

## 功能

- **今日**：eyebrow 是 `WORKDAY · SPROUT`。工作状态、倒计时、今日已赚、本月累计、进度、时/分/秒薪、购买力（首页只显示头两件）、备忘（可编辑）、小芽陪你。先赚回不放这一页。午休说明只在午休中出现；加班说明从加班开始时刻起才出现。加班中且当天是固定时薪时，时薪三列改按固定时薪拆。休息胶囊用焦糖，上班 / 加班 / 等待加班用深墨。打开「扣除支出」后，主卡、时薪三列和购买力改按扣除后口径（固定加班时薪本身不扣）
- **换算**：三档「先赚回 / 今天能换 / 想买的」。先赚回按月固定支出摊到每个上班日，对照毛收入的今日已赚看覆盖和净赚，不跟「扣支出」开关走；盖满当天支出后主卡进度条收掉。今天能换、想买的跟开关走。商品最多 5 件，双栏卡片，可改名称和单价，前两件不能删。想买的是单列票卡。先赚回、想买的「加一项 / 加一件」用深墨条；今天能换用浅底虚线卡。要改先点编辑，点完成才保存
- **日历**：当月格子。观看时点日期记加班（时长、开始时刻、平时秒薪或固定时薪）；休息日要先改成上班才能记。弹层进出场约 200ms。不是今天时副文案写当日收入（日薪 + 这天加班）。编辑态改休息制度或单日休息。法定节假日默认休息，调休补班默认上班。格子上假日标「休」、调休标「班」、加班标「加」。累计卡只写本月累计和上班天数；「扣支出」打开时累计改成扣除后口径
- **我的**：月薪、上下班、午休、扣除支出。本月有加班时，月薪框下写本月加班和总收入（月薪 + 本月加班）。没保存过月薪时输入框空着。每月工作日由日历算出，不手填。预览主数字是时薪

未保存过月薪时，倒计时和进度照常，金额显示「写月薪后就能看」。

工作状态：上班前 / 工作中 / 午休 / 等待加班 / 加班中 / 已下班 / 今天休息。

## 计算规则

完整公式、加班和休息日优先级见 [`docs/notes.md`](docs/notes.md)。实现在 `src/utils/work.ts`。节假日在 `src/utils/holidays.ts`。

今天休息时，倒计时停、今日已赚为 0。午休不计薪。加班不是劳动法倍率，按记录的分钟 ×（固定时薪或平时秒薪）。

默认班次：`09:00`–`19:00`，午休 `12:00`–`13:00`。存储里月薪默认 `12223`，未保存前不展示、设置页也不预填。节假日按国务院 2025、2026 年通知。

`Profile.workDaysPerMonth` 是遗留字段，界面不再手填，算薪用当月日历上班天数。

金额格式化不要用 `toLocaleString`（部分安卓微信会出问题），请用 `formatMoney` / `formatWage`。

## 本地开发

需要 Node.js 18+。

```bash
npm install --legacy-peer-deps
npm run dev:mp-weixin
```

然后用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入编译目录，**不要**导入源码根目录：

```
dist/dev/mp-weixin
```

正式打包：

```bash
npm run build:mp-weixin
```

产物在 `dist/build/mp-weixin`。`src/manifest.json` 里已填写微信 AppID；换自己的小程序时改 `mp-weixin.appid`。

分享走页面级 `onShareAppMessage`（右上角「…」），没有首页分享按钮。分享到朋友圈需要小程序发布后才会亮起。
